# Issue tracker: Jira

Issues and specifications for this repository live in Jira project `DS` on Dreamsoft Solutions' Atlassian instance.

## Project

- **Project key**: `DS`
- **Board**: [DS board 1](https://dreamsoftsolutions.atlassian.net/jira/software/projects/DS/boards/1?cloudId=5c00a27a-98a3-4871-95d1-ea33c5383ad2)
- **Issue keys**: Use Jira keys such as `DS-123`.

## Conventions

- **Publish**: Create the issue in Jira project `DS`.
- **Fetch**: Read the Jira issue by key, including its description, status, labels, assignee, and comments.
- **Update**: Use the Jira workflow to comment, assign, transition, and apply or remove labels.
- **Triage**: Use the labels mapped in `docs/agents/triage-labels.md`.
